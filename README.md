# 📅 Age Calculator

A simple age calculation utility implemented in multiple programming languages.

---

## 📖 Overview

This repository demonstrates how to calculate age using:

- JavaScript
- Python
- C#
- PHP

Useful for:

- Date calculations
- Utility applications
- Learning programming basics
- Backend practice

---

## ✨ Features

- Calculates age from birth year
- Console-based output
- Multi-language examples
- Beginner-friendly structure

---

## 📂 Structure

```text
javascript/
python/
csharp/
php/
```

---

## Example

### Input

```text
1998
```

### Output

```text
Age: 28
```

---

## Running

### JavaScript

```bash
node age.js
```

### Python

```bash
python age.py
```

### C#

```bash
dotnet run
```

### PHP

```bash
php age.php
```
